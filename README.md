# Milech y Luna: El Misterio del Núcleo Perdido

Página web de un cuento interactivo sobre Milech, un joven guerrero de 15 años, y su perrita Luna, que investigan un apagón en la ciudad tecnológica de Aldrath.

## Descripción
Una noche, toda Aldrath se queda sin luz y los robots guardianes se detienen. Milech y Luna siguen un mapa holográfico por el Bosque de Cables hasta la Torre Circuito, donde descubren que el apagón fue un pedido de ayuda del Núcleo, la fuente de energía de la ciudad.

## Características principales
- Menú de navegación con Bootstrap y desplazamiento a cada sección.
- Resumen del cuento, estilo contraportada.
- Sección de personajes principales con imágenes y descripción.
- Cuento completo, centrado y dividido en capítulos.
- Estilos propios con una paleta de azul noche, cian y plata.

## Tecnologías
HTML, CSS y Bootstrap 5.

## Control de versiones
El proyecto se desarrolló con Git y GitHub usando ramas (`estilos` y `contenidos`), merge y resolución de un conflicto.
