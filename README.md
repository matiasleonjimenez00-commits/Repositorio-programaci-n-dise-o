# Milech y Luna: El Misterio del Núcleo Perdido

Página web de un cuento interactivo sobre Milech, un joven guerrero de 15 años, y su perrita Luna, que investigan un apagón en la ciudad tecnológica de Aldrath.

## Descripción
Una noche, toda Aldrath se queda sin luz y los robots guardianes se detienen. Milech y Luna siguen un mapa holográfico por el Bosque de Cables hasta la Torre Circuito, donde descubren que el apagón fue un pedido de ayuda del Núcleo, la fuente de energía de la ciudad.

## Características principales
- Menú de navegación fijo con Bootstrap y desplazamiento a cada sección.
- Portada, resumen estilo contraportada y cuento completo dividido en capítulos.
- Sección de personajes con imágenes y descripciones.
- Galería de imágenes con filtros (Todas, Personajes y Lugares) y visor en grande hecho con JavaScript, con animaciones.
- Sección de contacto con los datos del autor.
- Diseño adaptable a computadora, tablet y celular.

## Tecnologías
HTML, CSS, JavaScript y Bootstrap 5.

## Estructura del proyecto
- `index.html`: página principal.
- `CSS/Styles.css`: estilos.
- `JS/galeria.js`: filtros, visor y animaciones de la galería.
- `IMG/`: imágenes del cuento.

## Control de versiones
El proyecto se desarrolló con Git y GitHub usando commits frecuentes, las ramas `estilos` y `contenidos`, merge y resolución de un conflicto.
